# Tablet Screener

แอป stock screener ส่วนตัวที่ใช้บนแท็บเล็ต สร้าง Watchlist ได้ไม่จำกัด เปรียบเทียบหุ้นด้วย P/E, P/BV, Market Cap, Div Yield, ROE, D/E, GPM, NPM

🔗 **เปิดแอป:** https://mornavapon.github.io/stock-screener-new-/

## แอปทำงานอย่างไร

1. `fetch_yahoo.py` ดึงข้อมูลหุ้นทุกตัวใน universe จาก Yahoo Finance
2. GitHub Actions (workflow ชื่อ **Update Stock Data**) รันสคริปต์วันละครั้ง แล้วบันทึกผลลงไฟล์ `stocks_data.json`
3. เว็บแอป (`index.html`) โหลด `stocks_data.json` ก้อนเดียว แล้วแสดงเฉพาะหุ้นที่อยู่ใน Watchlist ที่เลือก
   จึงไม่ต้องเรียก Yahoo Finance ทุกครั้งที่เปิดแอป
4. Watchlist ที่สร้างไว้ เก็บอยู่ในเครื่องที่ใช้เปิดแอป (สำรองไว้ด้วยปุ่ม **Export JSON**)

## วิธีเพิ่มรายชื่อหุ้นใหม่ที่ยังไม่มีในระบบ

### 1. ไปที่ไฟล์ `fetch_yahoo.py` ใน GitHub Repository

- เปิดไฟล์ `fetch_yahoo.py` แล้วกดปุ่มแก้ไข (รูปดินสอ)
- เพิ่ม Ticker Symbol ของหุ้นตัวใหม่เข้าไปในรายการ `tickers = [...]` ตามรูปแบบของ Yahoo Finance

| ตลาด | วิธีเขียนรหัส | ตัวอย่าง |
|---|---|---|
| หุ้นไทย | ต่อท้ายด้วย `.BK` | `"TU.BK"`, `"GPSC.BK"` |
| หุ้นสหรัฐฯ | ใส่ชื่อย่อตรงๆ (ถ้ามีจุด ให้เปลี่ยนเป็นขีดกลาง) | `"PLTR"`, `"CRWD"`, `"BRK-B"` |
| หุ้นฮ่องกง | รหัส 4 หลัก ตามด้วย `.HK` | `"1810.HK"`, `"0700.HK"` |
| หุ้นจีน A-Shares | ตามด้วย `.SS` (ตลาดเซี่ยงไฮ้) หรือ `.SZ` (ตลาดเสิ่นเจิ้น) | `"300750.SZ"`, `"600519.SS"` |

เมื่อแก้เสร็จ เลื่อนลงล่างสุดแล้วกด **Commit changes**

> สคริปต์ตรวจรหัสซ้ำให้อัตโนมัติ ถ้าใส่รหัสที่มีอยู่แล้ว ระบบจะข้ามตัวที่ซ้ำให้เอง

### 2. สั่งรัน Action เพื่อดึงข้อมูลใหม่เข้า JSON

1. ไปที่แท็บ **Actions** บน GitHub
2. คลิกที่ **Update Stock Data** ทางซ้ายมือ
3. กดปุ่ม **Run workflow** (หรือปล่อยให้ระบบรันอัตโนมัติตามเวลาที่ตั้งไว้)

เมื่อ Action รันเสร็จเรียบร้อย หุ้นตัวใหม่จะเข้าไปอยู่ใน `stocks_data.json` ทันที
จากนั้นเปิดแอปใหม่ (หรือรีเฟรชหน้า) แล้วพิมพ์ค้นหาชื่อหุ้นตัวนั้นที่ช่องค้นหาบนเว็บแอป เพื่อเพิ่มเข้า Watchlist ได้เลย

### ถ้าไม่เป็นไปตามที่คาด

- **ค้นหาแล้วไม่เจอหุ้น:** รหัสอาจยังไม่อยู่ในไฟล์, เขียนผิดรูปแบบ หรือ Action ยังรันไม่เสร็จ (ดูสถานะในแท็บ Actions) ถ้าเพิ่งรันเสร็จแล้วยังไม่เห็น ลองล้างแคชของเบราว์เซอร์หนึ่งครั้ง
- **หุ้นขึ้นเป็นขีด "-":** Yahoo Finance ไม่มีข้อมูลตัวนั้น หรือไม่มีค่านั้น (เช่น ไม่จ่ายปันผล) ดูข้อความ "เกิดข้อผิดพลาดในการดึงข้อมูล ..." ในล็อกของ Actions

## การใช้งาน Watchlist

- **สร้าง:** พิมพ์ชื่อที่ช่องล่างซ้าย แล้วกด `+` สร้างได้ไม่จำกัด
- **เพิ่มหุ้น:** พิมพ์ชื่อหรือรหัสหุ้นที่ช่องค้นหาด้านบน แล้วเลือกจากรายการ
- **ดูข้อมูลหุ้นเพิ่ม:** แตะที่ชื่อหุ้น เลือกดูงบจาก Yahoo Finance, กราฟจาก TradingView หรือถาม Claude
- **เรียงข้อมูล:** แตะที่ชื่อหัวข้อคอลัมน์ (แตะซ้ำเพื่อสลับมาก→น้อย / น้อย→มาก)
- **เรียงลำดับ Watchlist:** ลากที่ ☰ หรือกดปุ่ม **เรียง A→Z**
- **สำรอง / ย้ายเครื่อง:** ปุ่ม **Export JSON** และ **Import JSON** (การ Import จะแทนที่ Watchlist ทั้งหมดที่มีอยู่ในเครื่อง)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | เว็บแอป (หน้าจอทั้งหมด) |
| `fetch_yahoo.py` | รายชื่อหุ้นทั้งหมดที่จะดึงข้อมูล และสคริปต์ดึงข้อมูลจาก Yahoo Finance |
| `stocks_data.json` | ข้อมูลหุ้นที่ดึงมาแล้ว (สร้างและอัปเดตอัตโนมัติ ไม่ต้องแก้เอง) |
| `.github/workflows/update_data.yml` | ตั้งเวลาให้ GitHub Actions รันสคริปต์ดึงข้อมูล |

ข้อมูลทั้งหมดมาจาก Yahoo Finance อาจล่าช้าหรือคลาดเคลื่อนได้ ใช้ประกอบการตัดสินใจเท่านั้น ไม่ใช่คำแนะนำในการลงทุน

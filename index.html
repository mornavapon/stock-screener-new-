📖 วิธีเพิ่มรายชื่อหุ้นใหม่ที่ยังไม่มีในระบบ

1. เพิ่มรหัสหุ้นในไฟล์ fetch_yahoo.py บน GitHub

  • เปิดไฟล์ fetch_yahoo.py ใน GitHub Repository แล้วกดปุ่มแก้ไข (รูปดินสอ)
  • เพิ่มรหัสหุ้นตัวใหม่ลงในรายการ tickers = [...] ตามรูปแบบของ Yahoo Finance
ตลาดวิธีเขียนรหัสตัวอย่าง
หุ้นไทยต่อท้ายด้วย .BK"TU.BK", "GPSC.BK"
หุ้นสหรัฐฯใส่ชื่อย่อตรงๆ (ถ้ามีจุด ให้เปลี่ยนเป็นขีดกลาง)"PLTR", "CRWD", "BRK-B"
หุ้นฮ่องกงรหัส 4 หลัก ตามด้วย .HK"1810.HK", "0700.HK"
หุ้นจีน A-Sharesตามด้วย .SS (ตลาดเซี่ยงไฮ้) หรือ .SZ (ตลาดเสิ่นเจิ้น)"300750.SZ", "600519.SS"

เมื่อแก้เสร็จ เลื่อนลงล่างสุดของหน้าแล้วกด Commit changes

2. สั่งรัน Action เพื่อดึงข้อมูลใหม่เข้า JSON

  • ไปที่แท็บ Actions บน GitHub
  • คลิกที่ Update Stock Data ทางซ้ายมือ
  • กดปุ่ม Run workflow (หรือปล่อยให้ระบบรันอัตโนมัติตามเวลาที่ตั้งไว้)
เมื่อ Action รันเสร็จเรียบร้อย หุ้นตัวใหม่จะเข้าไปอยู่ใน stocks_data.json ทันที จากนั้นเปิดแอปนี้ใหม่ (หรือรีเฟรชหน้า) แล้วพิมพ์ค้นหาชื่อหุ้นตัวนั้นที่ช่องค้นหาด้านบน เพื่อเพิ่มเข้า Watchlist ได้เลย

💡 เกร็ดเล็กน้อย

  • ถ้าพิมพ์ค้นหาแล้วไม่เจอ แสดงว่ารหัสยังไม่อยู่ในไฟล์ หรือเขียนผิดรูปแบบ หรือ Action ยังรันไม่เสร็จ
  • ถ้าหุ้นขึ้นเป็นขีด "-" แสดงว่า Yahoo Finance ไม่มีข้อมูลตัวนั้น (ดูได้จากล็อกใน Actions)
  • Watchlist เก็บอยู่ในเครื่องนี้ ควรกด Export JSON สำรองไว้เป็นระยะ
